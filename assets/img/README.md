# Dokumentasi Folder: `assets/img/`

Folder `assets/img/` berisi seluruh aset grafis visual statis yang digunakan di seluruh aplikasi SIMPARK-UB, termasuk ikon vektor SVG murni, ilustrasi latar belakang (blob), dan gambar peta cadangan.

---

## 🎨 Katalog Aset Grafis

| Nama File | Format | Deskripsi & Tempat Penggunaan |
|---|---|---|
| `blob-blue.svg` | SVG | Latar belakang grafis abstrak biru untuk kartu rekomendasi utama di `index.html`. |
| `blob-blue-soft.svg` | SVG | Latar belakang dekoratif biru muda dengan transparansi lembut. |
| `blob-yellow.svg` | SVG | Aksen grafis kuning emas UB untuk elemen kontras visual. |
| `blob-yellow-soft.svg`| SVG | Latar belakang aksen kuning lembut. |
| `search-icon.svg` | SVG | Ikon kaca pembesar (search) untuk input teks pada `<simpark-input>`. |
| `chevron.svg` | SVG | Ikon panah bawah (dropdown chevron) pada pemilih gedung tujuan atau opsi pengurutan. |
| `ticket-qr.svg` | SVG | Placeholder QR Code visual untuk tampilan tiket statis sebelum di-generate secara dinamis. |
| `dot-success.svg` | SVG | Titik indikator status hijau (ketersediaan slot banyak / aman). |
| `dot-warning.svg` | SVG | Titik indikator status oranye (ketersediaan slot terbatas). |
| `dot-error.svg` | SVG | Titik indikator status merah (ketersediaan slot penuh / antrean padat). |
| `legend-recommendation.svg` | SVG | Ikon penanda legenda peta untuk zona rekomendasi utama. |
| `legend-alternative.svg` | SVG | Ikon penanda legenda peta untuk zona alternatif kedua. |
| `legend-full.svg` | SVG | Ikon penanda legenda peta untuk zona yang sudah penuh. |
| `map-ub.png` | PNG | Gambar tangkapan layar peta kampus Universitas Brawijaya sebagai fallback apabila koneksi OpenStreetMap offline. |

---

## 💡 Keunggulan Format SVG
1. **Resolusi Bebas Pecah**: Tampilan vektor SVG tetap tajam dan presisi di layar resolusi tinggi (Retina / QHD / 4K).
2. **Ukuran File Sangat Kecil**: Total aset di folder ini sangat ringan (< 100 KB), mempercepat waktu rendering halaman (*Zero Latency*).
